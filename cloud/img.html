引入 & 调用教程

第一步：引入 JS

在 HTML 中通过 script 标签引入 img_1.2.0.js：

<script src="https://cdn.jsdelivr.net/gh/ccouo-cn/JavaScript@main/cloud/img_1.2.0.js"></script>

引入后全局暴露 UTF8Stego 对象，包含 4 个方法：

方法参数返回值说明
UTF8Stego.encode(text)stringHTMLCanvasElement字符串 → 隐写图片
UTF8Stego.encodeToDataURL(text)stringstring字符串 → base64
UTF8Stego.encodeToBlob(text)stringPromise<Blob>字符串 → PNG Blob
UTF8Stego.decode(input)string|HTMLCanvasElement|File|BlobPromise<string>图片 → 原始字符串

第二步：编码调用示例

示例 1：字符串 → Canvas 图片

const canvas = UTF8Stego.encode("你好世界");document.body.appendChild(canvas);

示例 2：字符串 → DataURL（可直接赋给 img.src）

const dataURL = UTF8Stego.encodeToDataURL("hello world");const img = document.createElement("img");img.src = dataURL;

示例 3：字符串 → Blob 并下载

const blob = await UTF8Stego.encodeToBlob("保存为文件");const url = URL.createObjectURL(blob);const a = document.createElement("a");a.href = url; a.download = "stego.png"; a.click();

第三步：解码调用示例

示例 4：图片 URL → 字符串

const text = await UTF8Stego.decode("https://example.com/stego.png");console.log(text);

示例 5：本地文件 → 字符串（File 对象）

inputEl.addEventListener("change", async (e) => { const text = await UTF8Stego.decode(e.target.files[0]); console.log(text);});

示例 6：Canvas → 字符串

const text = await UTF8Stego.decode(canvasElement);console.log(text);
注意：URL 解码需目标服务器设置 CORS 响应头（Access-Control-Allow-Origin），否则浏览器会拦截跨域请求。建议使用本地图片或同源图片进行解码测试。或者使用官方代理http://cdn.ccouo.online/?url=图片url
